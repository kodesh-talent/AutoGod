## AutoGod-是什么？

AutoGod（自动化助手）是一款面向开发者和自动化测试人员的新一代Android自动化测试框架。它以安全性为核心设计理念，集成了强大的AI识别能力、极致的性能表现以及全面的防破解保护机制，帮助用户高效构建、运行和保护自动化脚本。无论你是个人开发者还是企业团队，AutoGod都能为你提供从脚本编写、调试到打包部署的一站式解决方案。



## AutoGod-能干什么？

App自动化测试：快速编写回归测试、UI自动化测试脚本。

游戏辅助自动化：利用OCR + YOLO识别实现游戏内自动操作。

企业RPA流程：构建跨应用的自动化业务流程。

脚本商业化保护：通过多层安全机制保护你的脚本知识产权。



## AutoGod-的优势？

内置Yolo全系列+主流OCR；

Material Design3精美UI开发；

兼容性强：覆盖Android 5+至Android 16全版本系统，完美适配雷电模拟器、云手机等平台。

完善的文档体系：提供API英文/中文文档、UI英文/中文文档，上手无门槛。

专业开发工具：内置IDEA开发插件，提供开发者后台管理系统。

# AutoGod 自动化助手 简介



【应用简介】

自动化助手(AutoGod)是新一代面向合法授权场景的安卓自动化效率工具，支持免ROOT、Shizuku、无障碍、HID等自动化方案、支持YoloV5-V13以及YoloX全系列目标检测方案、支持Paddle、Mlkit、Ncnn等多种OCR文字识别方案、支持全套谷歌MaterialDesign3风格UI界面设计方案；支持打包APK并且高度防逆向：JS代码经简化、混淆、VMP转码，企业级加密保护；专为开发者、软件测试人员优化，兼顾易用性与安全性。允许开发者自行编写简单的代码完成高度自定义的自动化流程，APP内置大量示例、文档、代码编辑器等功能。主要为企业办公、设备运维、应用测试等合规用途提供服务。软件通过用户显式授权实现触控模拟、流程自动化、本地 OCR 文字识别与图像匹配等功能，所有操作均在用户自有设备上本地完成，不采集、不上传用户隐私数据。



【核心功能】

一、OCR文字识别

内置多种主流OCR识别引擎（PaddleOCR、Google MLKit、PPOcrV5），精准识别屏幕文字内容，满足不同场景的文字定位需求。



二、YOLO目标检测

支持YOLO全系列模型（YoloV5-V13以及YoloX），轻松实现屏幕元素的目标检测与定位。



三、高级安全防护

1.防HOOK：打包时源码被转换为不可逆混淆码，使用VMP混淆引擎执行，APK中不存在任何可还原源码，完美抵御所有HOOK方案。

2.防抓包：传输协议高仿HTTPS，JSON字段加密混淆，采用高强度非对称加密传输；APK源码高强度混淆，无法进行有效的抓包分析。

3.防离线破解：本地与云端双端签名校验，部分脚本引擎存于云端，杜绝离线破解行为。

4.卓越的执行效率：打包后的APK脚本引擎直接执行混淆码，性能与开发阶段执行源码旗鼓相当，零性能损耗。



【产品优势】

拓展性强：支持加载APK、DEX、JAR、SO文件，并提供Plugin插件开发机制，灵活扩展功能。

兼容性强：覆盖Android 5+至Android 16全版本系统，完美适配雷电模拟器、云手机等平台。

文档体系：提供API英文/中文文档、UI英文/中文文档，上手无门槛。

专业开发工具：IDEA开发插件，提供开发者后台管理系统。



【适用场景】

APP自动化测试：快速编写回归测试、UI自动化测试脚本。

企业RPA流程：构建跨应用的自动化业务流程。

脚本商业化保护：通过多层安全机制保护你的脚本知识产权。
